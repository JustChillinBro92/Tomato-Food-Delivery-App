# Tomato Food Delivery App

A modern food delivery application built with JavaScript, HTML, and CSS.

## Features

- Browse restaurant menus
- Add items to cart
- Place food delivery orders
- User-friendly interface

## Tech Stack

- **Frontend**: JavaScript, HTML, CSS
- **Architecture**: Single-page application

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/JustChillinBro92/Tomato-Food-Delivery-App.git
cd Tomato-Food-Delivery-App
```

2. Open `index.html` in your web browser
```bash
open index.html
```

## Project Structure

- `index.html` - Main HTML file
- `styles.css` - Styling and layout
- `script.js` - Application logic

## Usage

Simply open the application in your browser and start browsing available restaurants and food items.
